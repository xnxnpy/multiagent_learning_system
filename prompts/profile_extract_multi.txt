## 可提取的 8 个维度

| 字段 | 含义 | 合法值说明 |
|------|------|-----------|
| major | 专业 | 学生原话中的专业名，如计算机、软件测试 |
| grade | 年级 | 仅允许：大一、大二、大三、大四、研一、研二、研三、博士 |
| goal | 学习目标 | 如考研、找工作、课程需要 |
| knowledge_level | 知识水平 | 如零基础、有编程语言基础、学过相关课程 |
| learning_style | 学习风格 | 仅允许：看视频、看文档、动手实践、做题 |
| coding_ability | 编程能力 | 仅允许：零基础、入门、会基础语法、中级、熟练、精通 |
| interests | 兴趣方向 | JSON 数组 |
| weakness | 薄弱点 | JSON 数组（清单回答也放入此字段） |

## 关键区分

- **「有编程基础 / 有编程语言基础 / 有一定基础 / 学过编程」** → 同时输出 knowledge_level + coding_ability（入门）
- 「我想考研 / 找工作」→ goal；「计算机 / 软件测试专业」→ major
- 同一句话里说的多个维度 → 都要输出

## 其他规则

1. 只提取学生明确说出的，禁止推断脑补
2. 学生没说的维度不要输出（字段缺失，不是空字符串）
3. **即使「已收集」里已有某值，学生这句话里明确说了，也必须输出**
4. 只输出一个 JSON 对象
